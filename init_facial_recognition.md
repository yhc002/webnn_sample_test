#Webnn facial landmark detection sample app

I want to create a sample test page which utilizes webnn facial landmark detection API.
Refer to https://github.com/webmachinelearning/webnn-samples/tree/master/facial_landmark_detection/ to understand how to implement the API.

From our test page we will request getUserMedia API to request camera video.
In our captured camera video I want to use facial landmark detection API to show how it is tracking facial features.
